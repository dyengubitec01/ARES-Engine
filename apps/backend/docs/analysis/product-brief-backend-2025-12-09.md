# Product Brief: backend

**Date:** 2025-12-09
**Author:** ARES team

---

## Executive Summary

**backend**는 사내 직원을 위한 통합 AI 게이트웨이 백엔드입니다.
여러 AI 서비스(Chatbot, RAG, 파일 저장소 등)를 하나로 연결하여,
인증된 직원만 사용할 수 있는 맞춤형 사내 AI 솔루션을 제공합니다.

핵심 가치는 "질문하면 관련 문서와 함께 AI가 답변"하는 경험을
안전한 사내 환경에서 제공하는 것입니다.

---

## Core Vision

### Problem Statement

사내 직원들은 업무에 필요한 문서를 수동으로 검색해야 하며,
이 과정에서 많은 시간이 소모됩니다. 또한 외부 AI 서비스는
보안 문제로 사내 문서에 활용할 수 없어, 사내 전용 AI 솔루션이 부재합니다.

### Problem Impact

- 문서 검색에 불필요한 시간 소모
- 사내 지식 활용도 저하
- 외부 AI 사용 시 보안 위험
- 업무 효율성 감소

### Why Existing Solutions Fall Short

| 기존 방식 | 한계 |
|----------|------|
| 수동 문서 검색 | 시간 소모, 비효율적 |
| 외부 AI (ChatGPT 등) | 사내 문서 연동 불가, 보안 위험 |
| 별도 문서 관리 시스템 | AI 연동 없음, 검색 한계 |

### Proposed Solution

NestJS 기반 통합 AI 게이트웨이로, 다음 서비스들을 연결합니다:
- **Chatbot Agent**: AI 대화 (SSE 스트리밍)
- **RAG 임베딩**: 문서 벡터화 및 검색
- **MinIO**: 문서 파일 저장
- **PostgreSQL**: 데이터 관리
- **Kafka**: 이벤트 로깅

Azure AD 인증을 통해 사내 직원만 접근 가능하며,
질문 시 관련 문서를 함께 제공하는 RAG 기반 AI 답변을 제공합니다.

### Key Differentiators

1. **사내 전용**: Azure AD 인증으로 보안 확보
2. **문서 기반 AI**: RAG로 사내 문서 기반 답변 제공
3. **통합 게이트웨이**: 여러 AI 서비스를 하나로 연결
4. **실시간 스트리밍**: SSE로 빠른 응답 경험

## Target Users

### Primary Users: 일반 직원

**프로필:**
- 사내 모든 직원
- Azure AD로 인증된 사용자

**주요 사용 시나리오:**
- 업무 관련 문서 검색
- AI에게 업무 질문
- 매뉴얼/가이드 검색
- 기존 문서 참고하여 초안 작성

**기대 가치:**
- 문서 검색 시간 단축
- 업무 효율성 향상
- 사내 지식 쉽게 접근

### Secondary Users: 관리자

**프로필:**
- DB 컬럼으로 구분되는 관리자 역할
- 권한 관리 담당자

**주요 기능:**
- 사용자 권한 관리
- 임베딩 요청 권한 부여
- 향후 새로운 권한 생성/관리

### 권한 구조

| 권한 | 일반 직원 | 관리자 |
|------|----------|--------|
| AI 대화 | ✅ | ✅ |
| 문서 검색 | ✅ | ✅ |
| 임베딩 요청 | 권한 필요 | ✅ + 부여 가능 |
| 권한 관리 | ❌ | ✅ |

> 권한 시스템은 확장 가능하게 설계하여 관리자가 새로운 권한을 추가할 수 있습니다.

## Success Metrics

### User Success Metrics

| 지표 | 설명 | 측정 방법 |
|------|------|----------|
| 답변 정확도 | AI가 관련 문서와 함께 정확한 답변 제공 | 피드백 긍정률 |
| 피드백 긍정률 | 사용자 좋아요 비율 | 좋아요 수 / 전체 피드백 |

### 피드백 시스템

- **좋아요/싫어요**: 각 AI 답변에 피드백 가능
- **데이터 활용**: 좋아요 받은 답변은 다음 임베딩 학습에 활용
- **DB 구조**: 답변 테이블에 `like_yn` 컬럼으로 저장

### Business Objectives

| 목표 | 설명 |
|------|------|
| 사용률 증가 | 전체 직원 중 활성 사용자 비율 증가 |
| 일일 활성 사용자 | DAU(Daily Active Users) 추적 |
| 질문 수 | 일일/주간 총 질문 수 |
| 피드백 참여율 | 답변 중 피드백을 남긴 비율 |

### Key Performance Indicators

| KPI | 목표 |
|-----|------|
| 피드백 긍정률 | > 70% |
| 피드백 참여율 | > 30% |
| 주간 활성 사용자 | 전 직원의 > 50% |

## MVP Scope

### 단계별 로드맵

| 단계 | 범위 | 핵심 가치 | 모듈 |
|------|------|----------|------|
| **1차 MVP** | 챗봇 연결 | AI와 대화 가능 | Auth + Chat |
| **2차** | 문서 기반 AI | 문서와 함께 답변 | File + Document + RAG |
| **3차** | 이벤트 로깅 | 분석/모니터링 | Event (Kafka) |

### 1차 MVP Core Features

| 기능 | 설명 |
|------|------|
| Azure AD 로그인 | 사내 직원 인증 |
| AI 질문 | Chatbot Agent에 질문 전송 |
| SSE 스트리밍 답변 | 실시간 AI 응답 |
| 피드백 | 답변에 좋아요/싫어요 |
| 헬스체크 | SSE 연결 상태 모니터링 |

### Out of Scope for MVP

| 제외 항목 | 이유 | 예정 단계 |
|----------|------|----------|
| 문서 저장/관리 | 문서 준비 전 | 2차 |
| RAG 임베딩/검색 | 문서 의존 | 2차 |
| Kafka 이벤트 로깅 | 핵심 기능 아님 | 3차 |

### MVP Success Criteria

- 직원이 Azure AD로 로그인할 수 있음
- AI에게 질문하고 SSE 스트리밍으로 답변을 받을 수 있음
- 답변에 피드백(좋아요/싫어요)을 남길 수 있음
- SSE 연결 상태를 헬스체크로 모니터링

### Future Vision

**2차: 문서 기반 AI**
- MinIO 파일 저장소 연동
- 문서 CRUD 기능
- RAG 임베딩 요청 및 문서 검색
- "질문하면 관련 문서와 함께 AI가 답변"

**3차: 분석/모니터링**
- Kafka 이벤트 로깅
- 사용 패턴 분석
- 시스템 모니터링
